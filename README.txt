ABI-TBS-Blocker 1.0
《暗區突圍：無限》封鎖 tbs_browser.exe 小工具

━━━━━━━━━━━━━━━━━━━━
這是什麼
━━━━━━━━━━━━━━━━━━━━
暗區的啟動器裡有一個內建瀏覽器 tbs_browser.exe，用來顯示啟動器裡的網頁內容（公告、活動等）。

2026 年 11 月，同樣由 Level Infinite 發行的《勝利女神：妮姬》電腦版，被發現啟動器內建瀏覽器載入的網頁檔案遭人竄改，部分玩家因此被裝上木馬。

目前沒有證據顯示暗區受到影響。這個工具是「預防用」的：用 Windows 防火牆禁止 tbs_browser.exe 連上網路，以後就算網頁檔案又被竄改，它也載入不了。

━━━━━━━━━━━━━━━━━━━━
怎麼用（30 秒）
━━━━━━━━━━━━━━━━━━━━
1. 先完全關閉暗區啟動器（右下角工作列的圖示按右鍵 → 結束）。
2. 對 ABI-TBS-Blocker.exe 按兩下。Windows 問「是否允許此應用程式對您的裝置進行變更」時，按「是」。
   （修改防火牆需要系統管理員權限）
3. 工具會自動找到 tbs_browser.exe，按「封鎖」。
4. 重新開啟暗區啟動器，確認可以正常登入、更新、開始遊戲。

找不到檔案時：按「手動選擇檔案…」，選遊戲資料夾裡的 launcher\service\tbs_browser.exe。

━━━━━━━━━━━━━━━━━━━━
副作用和還原
━━━━━━━━━━━━━━━━━━━━
‧ 啟動器裡的網頁內容（公告、活動頁面等）可能會變成空白。
‧ 如果啟動器因此無法登入、更新或開始遊戲：重新打開這個工具，按「解除封鎖」，就會完全恢復原狀。
‧ 遊戲改版後，如果 tbs_browser.exe 換了位置，封鎖會失效，重新執行一次工具就好。

跳出「Windows 已保護您的電腦」？

按「其他資訊」→「仍要執行」即可。

這個工具做了什麼（給想確認的人）
━━━━━━━━━━━━━━━━━━━━
‧ 只會新增或刪除一條 Windows 防火牆「輸出規則」，名稱是：
  Block tbs_browser.exe (Arena Breakout Infinite)
‧ 只處理暗區的 tbs_browser.exe，不會動到其他遊戲。
‧ 不會修改、刪除或下載任何檔案；本身不連網、不常駐、不會開機自動執行。
‧ 這條規則可以在「Windows 安全性 → 防火牆與網路保護 → 進階設定 → 輸出規則」看到，也可以在那裡手動刪除。
‧ source 資料夾裡是完整原始碼，可以自己檢查。
  Windows 10/11 內建編譯器，執行 source\build.bat 就能自己編譯出 exe，不必相信別人編好的檔案。
  （自己編譯出來的 exe 雜湊值會和下面不同，這是正常的）
‧ 如果你用的是防毒軟體附的防火牆（不是 Windows 防火牆），規則可能不會生效，工具畫面會提醒。
